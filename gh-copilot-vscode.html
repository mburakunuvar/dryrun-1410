01 / IDE

GH Copilot in VS Code

An AI agent works toward a goal by gathering context, using tools in your development environment, and evaluating what happened. In VS Code, you guide the work and decide which actions need approval.

From request to result

The agent loop

Each action gives the agent new information, so it can adjust and continue until the task is ready for your review.

  1. 01

    Set a goal

    Describe the outcome and any constraints.

  2. 02

    Gather context

    Relevant files and conversation history inform the model.

  3. 03

    Take action

    Tools let the agent inspect files, edit code, or run commands.

  4. 04

    Evaluate

    Results become context for the next decision or validation.

  5. 05

    Review

    Inspect the changes and validation results before keeping them.

The pieces around the loop

Work with agents on your terms

01 / SESSION

Keep work together

A session brings the conversation, task state, workspace, and code changes together. You can continue the work across supported agent experiences.

02 / ENVIRONMENT

Choose where work runs

An agent harness coordinates the model, tools, and session. Its execution environment can be your machine, a connected host, a Dev Container, or cloud infrastructure.

03 / CONTROL

Stay in control

Choose available tools and approval requirements. Add context, redirect or stop the agent, then review its changes and validation results.

04 / CAPABILITIES

Extend agent work

Use planning for complex tasks, delegate focused research to subagents, and tailor workflows with memory, custom agents, skills, and hooks.
